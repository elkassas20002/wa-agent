# لوحة واتساب الذكية — chat.keyprostore.com

لوحة ويب تربط واتساب بيزنس عن طريق رمز QR (مثل واتساب ويب)، وتعرض المحادثات وتتيح الرد عليها، وفيها مساعد يرد على المتدربين ويرسل لك تنبيهات بالرسائل المهمة.

## المتغيرات المطلوبة (Environment Variables)

| المتغير | إلزامي | الوصف |
|---|---|---|
| `ADMIN_PASSWORD` | نعم | كلمة مرور دخول اللوحة |
| `ANTHROPIC_API_KEY` | لا | إذا أضفته تصبح الردود والتقارير بالذكاء الاصطناعي. بدونه تعمل الردود بالكلمات المفتاحية مجاناً |
| `AI_MODEL` | لا | نموذج الذكاء الاصطناعي (الافتراضي `claude-haiku-5-5`) |
| `DATA_DIR` | لا | مكان حفظ الجلسة والمحادثات (الافتراضي `~/wa-agent-data` خارج مجلد الموقع حتى لا يُحذف عند إعادة النشر) |

## إعدادات النشر على Hostinger (Node.js)

- Framework / App type: **Express**
- Node version: **22**
- Entry file: **server.js**
- Build script: **build**
- Package manager: **npm**

## طريقة العمل

1. افتح الموقع وسجّل الدخول بكلمة المرور.
2. امسح رمز QR من تطبيق واتساب بيزنس: الإعدادات ← الأجهزة المرتبطة ← ربط جهاز.
3. من ⚙️ الإعدادات: اكتب معلومات التدريب والردود الجاهزة والكلمات المهمة.
4. اختر وضع المساعد من الأعلى:
   - **متوقف:** لا يرد ولا يقترح.
   - **يقترح الرد وأنا أرسل:** (ابدأ به) يكتب مسودة تحت المحادثة وأنت ترسلها.
   - **يرد تلقائياً:** يرد على الأسئلة الواضحة بعد تأخير بسيط.
5. الرسائل المهمة (شكوى، استرداد، مشكلة دفع…) لا يرد عليها المساعد. يعلّمها ويرسل لك تنبيهاً على واتساب في محادثتك مع نفسك، وفي المتصفح.
6. إذا رددت بنفسك من الجوال على أي محادثة، يتوقف المساعد فيها تلقائياً لمدة 12 ساعة (قابلة للتعديل).

## تنبيه

الربط يستخدم مكتبة غير رسمية (Baileys) تعمل مثل واتساب ويب. واتساب لا يسمح رسمياً بالأتمتة، فاستخدم الرد التلقائي باعتدال حتى لا يتعرض الرقم للتقييد.
